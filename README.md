# 🔍 Lean Stack Auditor

> Find bundle bloat and replace it with vanilla JavaScript

**Status:** 🚧 Building in public - Launching Jan 28, 2025

## What is this?

A CLI tool that analyzes your JavaScript projects and tells you:
- Which dependencies are bloated
- What vanilla JS alternatives exist
- How much money you're wasting on bandwidth
- Exactly what code to use instead
