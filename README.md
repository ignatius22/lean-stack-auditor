# Lean Stack Auditor 🔍

> Find bundle bloat and replace it with vanilla JavaScript

**Status:** 🚧 Building in public - Launch Jan 28, 2026

## What is this?

A CLI tool that analyzes your JavaScript projects and finds:
- Dependencies you barely use
- Vanilla JS alternatives that are smaller
- How much money you're wasting on bandwidth
